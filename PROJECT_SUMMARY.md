I developed a web-based Customer Relationship Management (CRM) application for Smarti Environmental Limited using Python, Streamlit and SQLite.

The application allows users to manage customer records, track onboarding progress, register staff members, schedule appointments and manage maintenance jobs. Staff can be assigned to jobs, and job statuses can be updated as work progresses. A dashboard provides an overview of customers, staff and jobs.

I am particularly pleased that I was able to build a working application that connects these different business processes into one centralised system. I also implemented database storage so that information is retained between sessions.

Throughout development, I used AI tools to support problem-solving, understand errors and assist with implementation. I tested the main features manually using fictional customer and staff records.

If I were to develop the application further, I would introduce user authentication, more advanced input validation, search and filtering, automated appointment reminders and more detailed reporting. These improvements would make the system more secure, scalable and suitable for use in a real business environment.
